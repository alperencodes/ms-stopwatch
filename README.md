# Beatmap Millisecond Stopwatch

A simple, dependency-free stopwatch for creating rhythm-game beatmaps with millisecond-accurate timestamps.

Open `index.html`, optionally select a song from `resources/songs`, and start the timer. Press **Y**, **Z**, or **X** to record notes and **Space** to pause or resume. Song playback follows start, stop, resume, and reset. Enter the song details and save the beatmap as JSON; recorded notes include an empty `lane` value to fill in later.
